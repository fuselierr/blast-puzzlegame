# L City

The basic description of our project starts with a 2D grid on the screen. A random amount of debris is scattered on random tiles. Mines that explode in 8 directions (horizontally, vertically, diagonally) are placable by the user. Each projectile sent by the mine can destroy 1 piece of debris. The objective of the game is to place the mines in a correct configuration in order to destroy all the debris within a time limit.

We have mostly considered what we want to focus on in our project proposal but more generally, a list of possible features include: several game modes such as campaign mode, where players progress through designed levels that introduce mechanics gradually, and Freeplay Mode, where levels are procedurally generated. Other modes include Streak, Time, Classic mode, Blast mode, daily challenges and stretch features such as leaderboards. The game could also have a level editor to encourage creativity and community engagement.
